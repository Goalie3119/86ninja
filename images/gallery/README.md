# Gallery photos

Drop build photos in this folder and they show up in the "Recent Builds" slider on the site.

- JPG, PNG, WEBP, GIF and AVIF all work.
- The file name becomes the caption. Use dashes between words:
  `gr86-1000-star-headliner.jpg` shows as "Gr86 1000 Star Headliner".
- Photos are shown in file-name order. To pick the order, start names with a number:
  `01-...jpg`, `02-...jpg`. The number isn't shown in the caption.
- Keep photos under about 1 MB each so the page loads fast on phones.
